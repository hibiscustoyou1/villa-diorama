# 北京故宫雪景水晶球

单文件 Three.js 互动场景：一只景泰蓝底座承托的玻璃水晶球，球内是落雪的太和殿
微缩庭院——重檐庑殿、金水河五桥、覆雪回廊、空中楼阁与 8200 片形态各异的实体
雪晶；球外是月夜水庭，河灯、孔明灯与红梅环绕木码头。

**零依赖运行**：无 npm、无 CDN、无外部模型、无网络请求——three.js r169 与
OrbitControls 已内联进单个 `index.html`（保留 MIT 许可声明），WebGL2 浏览器直接打开。

## 运行

直接用浏览器打开 `index.html`（Chrome / Edge / Firefox 桌面版，需 WebGL2）。

## 交互

| 操作 | 效果 |
| --- | --- |
| 拖动旋转 / 滚轮 | OrbitControls 环视水晶球（阻尼平滑） |
| 点击底座「起风」按钮 | 横向阵风扫雪，随后涡流回旋；连点叠加独立阵风（≤16 股，单股 ≤24s） |
| 长按按钮（180ms 后蓄力） | 蓄力至 1.65 倍，按钮前移+光环反馈 |
| 拖动球面 | 相机旋转的同时施加有上限的相机相对方向扰动 |
| 双击球面 | 较轻扬雪 |
| 画布聚焦后按空格 | 与点击「起风」同效 |

## 技术要点

- **双场景管线**：球内场景先渲染到离屏 RT（颜色+深度），玻璃球壳以屏幕空间
  折射采样（IOR 1.48，RGB 三通道轻微色散、菲涅耳、触碰涟漪）；水面为独立图层，
  节流预渲染平面反射（静止相机下内景 4 帧/外景 6 帧一次）。
- **确定性**：固定种子 LCG 驱动全部随机（雪晶形态/分布、石岸、脚印……），
  同一浏览器每次打开完全一致。
- **静态几何合并**：宫殿/底座/庭院静态件按材质合并批渲染，材质全局缓存。
- **雪晶物理**：8200 粒、8 类形态（树枝晶/薄板/蕨枝/针晶/短柱/团絮/碎冰/细粉）
  独立 InstancedBufferGeometry，逐粒位置/四元数/速度属性；形态阻力、薄片滑翔、
  侧风摆动、解析屋面+包围盒+空间索引碰撞；落地持续留存（总数守恒），强风摇动
  再松脱；帧步长 ≤0.08s 拆两子步。
- **风场**：阵风 burst 包络（主脉冲+两波回冲）+三个位置/轴持续变化的局部涡流，
  球壁附近径向内折返（避免贴壁白带），LUT 三线性采样供粒子查询。

## 验收 API

打开页面后控制台可用 `window.__forbiddenCityGlobe`：

- `audit()` — 粒子非有限值/球体越界/低于表面/实体穿入/JS·shader 错误，全 0 时 `ok:true`
- `auditSnowInteraction()` — 活动阵风数、点击数、上扬/停留/重生计数、八类分布、四元数模长误差
- `auditPlaque()` — 铭牌顶点最大径向距离（< 球半径 6.7）

## 构建与验证

```
node tools/assemble.mjs        # src/*.js + 内联 three r169 → index.html
node verify/verify.mjs         # Playwright 无头验收（audit+交互+四视角截图）
```

`src/` 下 15 个模块按文件名序拼接（010-constants → 150-loop）。
`verify/` 需 Playwright + Chromium（见 package.json devDependencies）。

## 边界声明

1. 本作品为**艺术微缩**，非测绘复原；建筑比例与布局经过球内构图取舍。
2. 雪碰撞采用**代理表面近似**（解析屋面函数+包围盒+空间索引），非逐构件精确碰撞。
3. 玻璃与水为**实时屏幕空间近似**（离屏场景采样+平面反射节流），非离线光线追踪。
4. 河灯/孔明灯为**受约束的艺术动画**（椭圆水道内漂移、缓升），非流体求解。
5. 不显示实时天气；雪量与月光为固定艺术设定。
6. 无人物、无界面面板；交互仅「起风」与视角控制。
